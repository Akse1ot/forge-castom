# Установка Forge Custom Set Builder 1.0 в Codex (Windows)

## Путь

`D:\1\forge\.agents\skills\forge-custom-set-builder\SKILL.md`

`.agents` — обычная папка, если её нет, **создай вручную**. Никакой регистрации «агента» не требуется. Распакуй **содержимое внутренней папки** `forge-custom-set-builder` в этот путь (не допусти двойной вложенности `forge-custom-set-builder\forge-custom-set-builder`).

Если уже установлен v0.1 или v0.2, **не накладывай их справочники поверх 1.0**: сначала сохрани отдельно любые собственные изменения, затем замени папку навыка версией 1.0. Не меняй существующий `D:\1\forge\AGENTS.md`.

Папка навыка хранит `SKILL.md`, `SPECIFICATION.md`, `references`, `scripts`, `templates` и `NEW_SET_PROMPT.md`. Процедура первого запуска — `references/first-run.md`. Создание папки само по себе не меняет Forge и не запускает задачу.

## Проверка

Открой **новую сессию Codex с рабочей директорией `D:\1\forge`**. Если нужно, перезапусти приложение. Посмотри `/skills` или вызови `$forge-custom-set-builder`. Убедись, что Codex видит файл `SKILL.md`.

**Первый запуск:** используй `references/first-run.md` с явными ограничениями задачи. Он описывает разовую сверку архивов и текущего Forge, **без новых карт, Java-правок и удаления временных материалов**. Ссылка на `FIRST_RUN_PROMPT.md` в прежней инструкции не соответствовала установленным файлам (проверено 30.10.2026).

**Первый пилот:** после проверки первого отчёта заполни `NEW_SET_PROMPT.md` ссылкой на новый выпуск, видом и составом бустера. Не запускай пилот автоматически при установке.

## Удаляемые материалы

Текущие файлы аудитов `D:\1\forge-audit\DWAP*` — лишь разовые источники первого запуска; навык не должен на них зависеть после консолидации. Удалять их только **самостоятельно и после проверки** либо архивировать по желанию. `SPECIFICATION.md` и справочники постоянны.

## Политика безопасности

Java-код локального Forge может меняться **лишь после отдельного утверждения**. Сами скрипты/токены/картинки/editions всегда остаются за пределами игровых каталогов для ручного переноса.
