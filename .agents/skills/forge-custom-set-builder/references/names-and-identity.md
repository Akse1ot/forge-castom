# Идентичность выпуска и совпадения имён

**Источник правила:** утверждённая пользователем схема. Точный формат некоторых сложных многочастных файлов зависит от текущих правил Forge; проверяй локальные примеры.

1. Закрепи `Code` из ровно четырёх ASCII-букв A–Z; проверь `Code=` всех доступных `forge-gui/res/editions`, case-insensitive. Предпочитай инициалы названия, затем свободные осмысленные четырёхбуквенные сочетания. Не требуй подтверждения обычного конфликта, но отрази выбранный код в отчёте. Не менять код при продолжении.
2. Строй индекс занятых имён прежде всего из `Name:` текущей локальной базы скриптов и всех уже назначенных имён этого выпуска; проверь записи editions. Наличие файлов с тем же базовым именем тоже сигнал коллизии Windows. Ищи точное совпадение после нормализации регистра, не превращай частичные совпадения в полные.
3. Отделяй **игровую карту** от её лиц, артов и версий: две иллюстрации одного source_id не требуют отдельного суффикса. Если у выпуска две самостоятельные карты с одинаковым именем, суффикс назначается следующему свободному игровому имени.
4. Коллизия `Brimstone Mage` → первое свободное `Brimstone Mage I` (`II`, `III`, `IV`...). Римские суффиксы всегда через пробел. Строки: `Name:Brimstone Mage I`, `[cards]` → `1 R Brimstone Mage I`; файлы: `Brimstone_Mage_i.txt`, `Brimstone Mage i.fullborder.jpg` по принятой схеме; подлинный шаблон для многочастных карт/особых изображений определяй по локальному Forge.
5. Создай стабильную таблицу соответствий `source_id/URL | original_name | forge_name | script_file | image_file | edition_number` (например, `source/name-map.csv`), включая **незавершённые** карты. Избегай автоматического переназначения имён при возобновлении работы; проверяй, что зарезервированное имя не занял кто-то другой, и сообщай о конфликте.
6. Ссылки `Card.named...`, `Name$...` и связанные зависимости обновляй только при реальной необходимости, обдумав, на какой конкретно объект ссылается текст. **Oracle — авторская формулировка:** не менять автоматически все упоминания оригинального имени на Forge-суффикс.
7. Незавершённые карты остаются в editions закомментированными **под уже закреплённым** именем Forge.

Примечание: сам римский суффикс — пользовательское соглашение об уникальных именах, а не автоматическая функция Forge. Не полагайся на то, что Forge сам распознаёт исходное имя без суффикса.
