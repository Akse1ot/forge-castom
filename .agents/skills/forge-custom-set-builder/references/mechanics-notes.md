# Механики — проверенные решения

Добавляй сюда только повторно полезные решения, **проверенные по текущему Forge**. Указывай статус, дату/контекст, точный скриптовый интерфейс, затронутые Java-классы, ограничения и пример.

Предыдущие кастомные механики (например, Resonance, Ash of War, InvokeSkill, Epitome) **могут** присутствовать в проекте; не считай их API подтверждённым до проверки текущих локальных исходников. Не инициируй глобальный аудит этих механизмов: это отдельный проект.
