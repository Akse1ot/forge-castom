# Первый прогон на локальном Forge

1. Проверь доступность репозитория и существующий `AGENTS.md`. Не редактируй его.
2. Проверь, что `.agents/skills/forge-custom-set-builder/SKILL.md` доступен и прочитан.
3. В режиме `import` изучи локальный `D:\1\forge-audit\DWAP\source-cards.json`, если он существует. Выведи структуру, число записей, долю полных/неполных полей, типы многочастных карт и данные происхождения. Не делай вывод, что формат совпадает с нашим `templates/example-cards.json`.
4. Сопоставь схему DWAP с нашей нормализованной схемой; предложи простой адаптер как отдельный скрипт, но без его реализации до проверки настоящего формата.
5. Изучи тест `DWAPCardScriptTest.java`. Раздели тесты загрузки и игровые проверки. Подготовь перечень паттернов для общего тестового шаблона.
6. Представь отчёт и минимальный план следующего этапа. Не создавай и не меняй файлы карты/движка.

## Результат и повторное использование — 30.10.2026

**Статус: выполнена адресная сверка**, без генерации, Maven и повторного аудита карт. Оба сводных отчёта и итоговые строки логов доступны: исторически 18 и 17 успешных сценариев. Также проверено наличие подробного отчёта, списка изменений по картам, HTML, JSON, before/DWAP и follow-up diff; большие diff и полный HTML не перечитывались. Все перечисленные пользователем материалы доступны. Постоянный `DWAPCardScriptTest.java` прочитан, helpers AITest и соответствующие Java-участки сверены; контекст рабочего дерева — `engine-notes.md`.

Новые технические границы сохранены в `engine-notes.md`, приёмы тестов — `validation.md`, схема JSON — `sources-and-images.md`. Исторические выводы остаются в `dwap-lessons.md` и `ai-hints.md`; переписывать их не потребовалось. Новые общие механики не исследовались, `mechanics-notes.md` не заполнялся.

**Независимость:** долговременные выводы, отображение полей и ограничения находятся внутри навыка; в scripts/templates нет необходимости читать временные аудиты для нового выпуска. Указанный выше архивный путь — только необязательный вход разовой процедуры: если архива нет, использовать сохранённые знания и проверять актуальный Java, не восстанавливать исторические материалы по памяти. Полный исходный каталог, изображения, история конкретных правок и доказательные логи в навык намеренно не копировались. С точки зрения работы Skill временные папки DWAP можно удалить; для воспроизведения исторического аудита они всё ещё ценны. Ничего не удалялось.
