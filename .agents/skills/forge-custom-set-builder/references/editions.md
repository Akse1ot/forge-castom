# Editions и бустеры: работа по заданию пользователя

Три образца (**только** синтаксические примеры, не шаблон для копирования вслепую): `Core Set 2020.txt` (M20, классический), `Aetherdrift.txt` (DFT, сложные слоты), `The Exploration of Whisperwild.txt` (TEOW, недрафтовый). Их содержимое может находиться вне навыка; отсутствие этих файлов не блокирует работу — смотри текущие `forge-gui/res/editions` и парсер. Если образцы даны в задаче, изучи их. У DFT встречались дублированные `Prerelease`/`BoosterBox` с разными значениями: не копируй неоднозначности.

## Единственный источник состава бустера — задание пользователя

- **Classic Draft:** простой `Booster=...` со слотами `Common`/`Uncommon`/`RareMythic`/земли согласно конкретным требованиям. У M20 был `10 Common`, `3 Uncommon`, `1 RareMythic`, `1 land` и sheet-фильтры.
- **Custom Draft:** `BoosterSlots`, `Booster`, секции slots с `Base=...`, `Replace=...`, выборками и редкостями **строго по заданной** схеме. У DFT пример включает `Common-Guest`, `AnyLand`, `Wildcard`, `WildcardFoil`; фактический синтаксис и вычисление вероятностей проверить по текущей версии Forge.
- **Non-draft:** `[metadata]`, `[cards]`, `[tokens]` и другие необходимые секции **без собственного `Booster`**. `Type=CUSTOM_SET` и любые редкости проверять по локальным форматам; не делать всю коллекцию Rare/Mythic искусственно.

Если состав бустера не задан или несовместим с текущим Forge — отразить проблему **на этапе плана**. Не конструировать собственный баланс.

## Список и пропуски

- В `[cards]` записывать утверждённое `forge_name` из карты соответствий. Номер и редкость сохранять по источнику; если нумерации нет, присваивать стабильные номера.
- **Не реализована:** оставить на своей позиции `# 103 R Card Name`, не сдвигать следующие номера; отдельно вести список блокеров. Существующие строки комментариев `#` встречаются в editions, но подтвердить их обработку по парсеру локальной версии.
- Многочастные карты и альтернативные арты: не путать **число физических карт**, **число скриптов** и **число лиц**. Альтернативные изображения не дублируют скрипт; особые секции (promo, borderless, tokens) — только если они реально нужны набору.
- Проверить все используемые листы/секции, что pool после исключения закомментированных карт способен заполнить каждый обязательный слот, и что пробные бустеры технически соответствуют схеме (слоты/количество/запретные исключения). Не обещать гарантированную корректность вероятностей без соответствующих тестов.
