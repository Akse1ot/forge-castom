# Исторические уроки двух проходов DWAP

**Выпуск:** Drauholm: Winter's Approach (`DWAP`), PlaneSculptors: https://www.planesculptors.net/set/drauholm-winters-approach#cards. **Дата аудитов:** 29.10.2026. Это подтверждения из отчётов и patch-diff локальной версии, **не вечные факты о Java API**, не заменяют текущие исходники.

## Первый проход

- Проанализированы 252 скрипта; изменены 239 файлов, из них 212 содержательно, 27 только конца файла. 57 затронули строки реализации/keyword/SVar за пределами AI-подсказок, 75 — Oracle, 146 — Deck-поля (пересекающиеся категории).
- Для 251 имён совпадение прямое; исходное `Spinner of Souls` связано с локальным `Spinner of Souls I` без переименования; это особенно важно для будущего правила конфликтов имён.
- Источник был сохранён в HTML/JSON. `Malleable Fae` 2/1, `Foraging Raccoon` 1/1, `Yearling Warrior` 1/3 — отдельные пользовательские решения, не считавшиеся автоматически доказанными текстом сайта.
- `The Original Valkyria`: текст глав на изображении, противоречие «after IV» и видимых трёх глав. Не править спорный авторский материал догадкой.
- Показательные типы ошибок: неверная цель (`Frosted Grotto`), обязательная/необязательная цель (`Primal Rebuke`), возврат до смены зоны (`Cage the Soul`), неверный источник LKI (`Forged in Duty`), ссылочный SVar, token amount/цвет/тип, условия просветления (`Enlightened`), cast/activation cost, спеллы в ход оппонента.
- Согласно логу Java 17, 18 тестов прошли, BUILD SUCCESS. Доказательство загрузки скриптов/выборочных сценариев, не полной игровой корректности набора.

## Follow-up

- По изменённым 146 Deck-наборам просмотрена семантика `DeckHints`/`CardRulesPredicates`/`CardRanker`; исправлены 67 скриптов, 60 из-за представления нескольких возможностей в DeckHas, 7 с содержательными замечаниями.
- Пример: `DeckHas:Ability$Token & Ability$LifeGain` и `DeckHas:Ability$Token|LifeGain` были неэквивалентны по `deckHasExactly`; подробности `ai-hints.md`.
- Показательные смысловые ошибки: нет собственного Sacrifice у `Gunvald`, `Steinar`, `Tungskul`, `Grave Reckoning`; у `Aurora Strix` собственный Sacrifice за дополнительную стоимость, но Discard делают оппоненты; у `Unto Death` не собственный Discard.
- У `Primal Rebuke` исправлены `ValidTgtsDesc` и избыточное `DeckNeeds:Type$Shaman`.
- 17 выбранных тестов в отдельном запуске Java 17, 0 ошибок. Примеры: Snowslide перепроверка цели и смена Equipment до разрешения; Primal Rebuke Shaman/planeswalker/up-to; Skadi гибридная мана/optional target; Star-Herd Apprentice ограничение активации и смена игрового объекта; дополнительные стоимости Aurora Strix, несколько оппонентов Grave Reckoning, Tungskul. Это **не** +17 уникальных тестов поверх 18: наборы могут пересекаться.
- Не подтверждены все варианты оплаты `unless` у Tungskul/Grave Reckoning, фактическая UI-оплата гибридной маны у Skadi и качество Draft AI.

## Что переносим в долгосрочные правила

Проверка полных источников и лиц, отделение Oracle от семантики, связь карт с именами Forge, понимание контроллера действий, строгая работа с `DeckHas/Hints/Needs`, минимальные тесты через реальную игровую цепочку, осторожное использование старых локальных решений. **Полные исторические diff/логи/HTML не являются обязательными файлами для нового выпуска.**
