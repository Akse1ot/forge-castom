Источник/дата, выбранный тип и пользовательская схема бустера.

## Итоги

- Записей карт в оригинале / лиц / учтено в editions:
- Готово (A, B, C) / нереализовано / частично / требует уточнения:
- Успешная структурная загрузка / адресные игровые тесты / что не проверялось:
- Фактические Java-патчи: изменённые файлы и одобрение, либо «нет»:
- Пробные бустеры: слоты, число карт и выявленные ограничения, либо non-draft:

## Ручная установка

Точные **локальные источники staging** (`cards/`, `tokens/`, `editions/`, `images/`) → проверенные **целевые каталоги текущего Forge**. Пользователь выполняет перенос сам; не удалять и не копировать автоматически.

## Не удалось подготовить

- Нет полных изображений карт:
- Нет изображений токенов:
- Нет изображений эмблем/прочих объектов:
- Неясности исходного текста:

## Для очистки

Какие временные исходники и логи можно удалить **после проверки пользователем**; какие знания обобщены в Skill. Не считать временные пути долгосрочной зависимостью.
