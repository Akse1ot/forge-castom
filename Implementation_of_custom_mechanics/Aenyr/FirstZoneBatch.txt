Этот патч добавляет в движок общий механизм проверки первого batch-а перемещения карт между зонами за текущий ход.

Batch — это группа zone-change событий, которые происходят как одно общее событие движка.

Например, если два существа одновременно погибают от state-based actions или массового эффекта, они должны считаться одним batch-ем смертей. Это важно для формулировок вроде:

“if it’s the first creature that died this turn”

Если одновременно умерло несколько существ и это первая смерть существ в этом ходу, каждый их ChangesZone-триггер должен видеть, что он относится к первому batch-у.

Без batch-механизма движок мог бы воспринимать такие смерти как отдельные последовательные события:

```text
существо 1 умерло — первое
существо 2 умерло — уже не первое
```

Это было бы неправильно для одновременного события.

Патч исправляет именно эту проблему: одновременные перемещения объединяются одним batch-id, и все карты внутри этого batch-а получают одинаковый результат проверки.

Существующий оператор:

Count$ThisTurnEntered

отвечает на вопрос:

“Сколько подходящих карт уже вошло в эту зону за ход?”

Новый оператор:

Count$FirstBatchThisTurnEntered

отвечает на другой вопрос:

“Относится ли текущее событие к первому подходящему batch-у за этот ход?”

Это разные задачи.

`ThisTurnEntered` полезен для подсчёта количества событий или карт.

`FirstBatchThisTurnEntered` полезен для условий, где важен именно первый случай события, но нужно корректно обработать одновременность.

Например, если одновременно умерли три существа, обычный подсчёт может показать, что в кладбище вошло уже три существа. Но для условия “if it’s the first creature that died this turn” все три смерти всё ещё относятся к первому batch-у смертей.

Ограничения патча

Патч работает только с событиями перемещения карт между зонами, то есть с ChangesZone.

Также текущий синтаксис требует указать Destination. То есть оператор хорошо выражает:
первая карта вошла в Graveyard
первая карта вошла в Exile
первая карта вошла в Battlefield

Но не выражает напрямую:
первая карта покинула Battlefield куда угодно

Практическое назначение

Основное назначение патча — дать кастомным картам возможность корректно проверять формулировки вида:

```text
if it’s the first creature that died this turn
if it’s the first artifact put into a graveyard this turn
if it’s the first card exiled from the battlefield this turn
if it’s the first creature returned from your graveyard this turn
```

Применение в скриптах

Патч добавляет новый оператор:

```text
Count$FirstBatchThisTurnEntered_<Destination>[_from_<Origin>]_ <Valid>
```
Пример проверки условия срабатывания триггера:

```text
T:Mode$ ChangesZone | Origin$ Battlefield | Destination$ Graveyard | ValidCard$ Creature.Other | TriggerZones$ Battlefield | ConditionCheckSVar$ X | ConditionSVarCompare$ EQ1 | Execute$ TrigCharm | TriggerDescription$ Whenever another creature dies, if it’s the first creature that died this turn, ABILITY
SVar:X:Count$FirstBatchThisTurnEntered_Graveyard_from_Battlefield_Creature
```

Логика работы:

* GameAction открывает batch для zone-change событий;
* каждое фактическое ChangesZone событие записывается в Game;
* Game хранит журнал zone-change batch-событий до cleanup;
* AbilityUtils только парсит новый Count$ оператор и спрашивает Game, является ли текущий batch первым подходящим;
* в конце хода журнал очищается.

Такой вариант не зависит от того, когда впервые был вызван Count$ оператор, и корректно обрабатывает случай, когда первая смерть произошла до появления карты с соответствующим триггером.

```java
    public void beginZoneChangeBatch() {
        if (zoneChangeBatchDepth == 0) {
            currentZoneChangeBatchId = UUID.randomUUID();
        }
        zoneChangeBatchDepth++;
    }

    public void endZoneChangeBatch() {
        if (zoneChangeBatchDepth <= 0) {
            zoneChangeBatchDepth = 0;
            currentZoneChangeBatchId = null;
            return;
        }

        zoneChangeBatchDepth--;
        if (zoneChangeBatchDepth == 0) {
            currentZoneChangeBatchId = null;
        }
    }

    public UUID getCurrentZoneChangeBatchId() {
        return currentZoneChangeBatchId;
    }

    public void recordZoneChangeBatch(final ZoneType origin, final ZoneType destination, final Card card) {
        if (destination == null || card == null || currentZoneChangeBatchId == null) {
            return;
        }
        zoneChangeBatchRecordsThisTurn.add(new ZoneChangeBatchRecord(origin, destination, card, currentZoneChangeBatchId));
    }

    /**
     * Returns true if the current batch is the first batch this turn that contains
     * a matching zone-change event.
     */
    public boolean isFirstBatchThisTurn(final ZoneType destination, final ZoneType origin,
            final String validFilter, final UUID batchId, final Player player,
            final Card source, final CardTraitBase ctb) {
        if (destination == null || validFilter == null || validFilter.isEmpty() || batchId == null) {
            return false;
        }

        final String[] valid = validFilter.split(",");
        for (final ZoneChangeBatchRecord record : zoneChangeBatchRecordsThisTurn) {
            if (record.destination != destination) {
                continue;
            }
            if (origin != null && record.origin != origin) {
                continue;
            }
            if (record.card.isValid(valid, player, source, ctb)) {
                return batchId.equals(record.batchId);
            }
        }

        return false;
    }

    public void clearZoneChangeBatchRecordsThisTurn() {
        zoneChangeBatchRecordsThisTurn.clear();
    }
```

```java
    public final CardCollection sacrifice(final Iterable<Card> list, final SpellAbility source, final boolean effect, Map<AbilityKey, Object> params) {
        Multimap<Player, Card> lki = MultimapBuilder.hashKeys().arrayListValues().build();
        final boolean showRevealDialog = source != null && source.hasParam("ShowSacrificedCards");

        CardCollection result = new CardCollection();

        final UUID prevBatch = game.getCurrentZoneChangeBatchId();
        if (prevBatch == null) {
            game.beginZoneChangeBatch();
        }
        try {
            for (Card c : list) {
                if (c == null) {
                    continue;
                }

                if (!c.canBeSacrificedBy(source, effect)) {
                    continue;
                }

                Card lkiCopy = ((CardCollection) params.get(AbilityKey.LastStateBattlefield)).get(c);
                c.getController().addSacrificedThisTurn(lkiCopy, source);
                lki.put(c.getController(), lkiCopy);

                c.updateWasDestroyed(true);

                Card changed = sacrificeDestroy(c, source, params);
                if (changed != null) {
                    result.add(changed);
                }
                if (showRevealDialog) {
                    final String message = Localizer.getInstance().getMessage("lblSacrifice");
                    reveal(result, ZoneType.Graveyard, c.getOwner(), false, message, false);
                }
            }
        } finally {
            if (prevBatch == null) {
                game.endZoneChangeBatch();
            }
        }

        for (Map.Entry<Player, Collection<Card>> e : lki.asMap().entrySet()) {
            final Map<AbilityKey, Object> runParams = AbilityKey.mapFromPlayer(e.getKey());
            runParams.put(AbilityKey.Cards, new CardCollection(e.getValue()));
            runParams.put(AbilityKey.Cause, source);
            game.getTriggerHandler().runTrigger(TriggerType.SacrificedOnce, runParams, false);
        }
        return result;
    }
```

Назначение:

* если sacrifice вызывается внутри уже открытого batch-а, используется внешний batch;
* если sacrifice вызывается обычным массовым эффектом, весь список жертв объединяется в один batch.
