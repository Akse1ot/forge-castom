# My Custom Forge Fork

This repository is a personal custom fork of **Forge: The Magic: The Gathering Rules Engine**.

It is used for private development, experimentation, and implementation of custom mechanics, cards, and engine changes.

## Important Notice

This repository is **not** the official Forge project.

I am **not affiliated with the original Forge team** and do not represent its authors or maintainers.

If you are looking for the official Forge project, please visit the original repository:
[Card-Forge/forge](https://github.com/Card-Forge/forge)

## About This Fork

This fork contains custom changes that may include:
- new mechanics
- custom cards and scripts
- engine patches
- experimental features
- personal testing content

Because of that, behavior here may differ from the official Forge project.

## Purpose

This repository exists mainly for:
- personal development
- testing custom MTG content
- modifying Forge for custom sets and mechanics

It is not intended to be treated as an official upstream source.
