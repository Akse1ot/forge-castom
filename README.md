# My Custom Forge Fork

This repository is a personal custom fork of **Forge: The Magic: The Gathering Rules Engine**.

It is used for private development, experimentation, and implementation of custom mechanics, cards, and engine changes.

## Important Notice

This repository is **not** the official Forge project.

I am **not affiliated with the original Forge team** and do not represent its authors or maintainers.

If you are looking for the official Forge project, please visit the original repository:
[Card-Forge/forge](https://github.com/Card-Forge/forge)

## About This Fork

This fork contains custom changes that may include:
- new mechanics
- custom cards and scripts
- engine patches
- experimental features
- personal testing content

Because of that, behavior here may differ from the official Forge project.

## Custom Card Sets Added to the Engine

(The card mechanics and scripts are currently undergoing testing. Full functionality is not guaranteed.
)

### Aenyr

Aenyr is a new plane of the Multiverse where Art is the source of all Magic. Aenyr is a complete custom Magic: The Gathering set designed to be playable in both Limited and Constructed environments.

It is a highly polished, well-designed, and engaging set that has received very positive feedback from players. More information about the set, its archetypes, mechanics, and design can be found on the [author's page](https://doortonothingness.wordpress.com/2016/04/19/aenyr/).

### Elden Ring: The Lands Between

A set based on *Elden Ring* and its DLC, *Shadow of the Erdtree*. It contains spoilers for both games.

This is a large and ambitious set with many interesting mechanics, although some of them stretch or depart from conventional Magic: The Gathering rules and design practices. More information can be found on the [set's PlaneSculptors page](https://www.planesculptors.net/set/elden-ring-the-lands-between#details).

The set currently appears somewhat unbalanced in actual gameplay. However, this may partly be due to the complexity of its mechanics, many of which are difficult for Forge's AI to use effectively. Games against human opponents may therefore play quite differently.

### Canovol

Canovol, the plane's supervolcano and namesake, looms over the lives of its inhabitants. To some, it is a wrathful god; to others, the source of all life and magic. In a time when myths still hold true and much of the world remains unexplored, ten sentient races are beginning to become aware of one another. As tensions rise and cultures clash, it becomes apparent that not everyone has been adhering to the one rule that seems to run like a common thread through all civilizations...

Canovol is a 300-card set built around ten two-colour factions. Rather than guilds, ten familiar and lesser-known creature types receive their own Canovol interpretation, each with a distinct custom mechanic. The set can be drafted on its own or combined with other sets for Constructed play. [More information](https://www.planesculptors.net/set/canovol).

### Drauholm

Welcome to Drauholm, a plane loosely inspired by Nordic mythology, with a mechanical identity built around updated takes on mechanics returning from the author's previous sets.

[More information and the complete set on PlaneSculptors](https://www.planesculptors.net/set/drauholm-winters-approach).
